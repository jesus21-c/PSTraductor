# PSTraductor
PSTraductor permite usar el mando DualShock 4 en Windows como un control Xbox 360 virtual por ViGEmBus, habilitando transmisión de audio estéreo inalámbrico por Bluetooth (jack y altavoz), efectos rítmicos en la barra LED y lectura de batería en tiempo real, todo sin necesidad del adaptador oficial de Sony.
